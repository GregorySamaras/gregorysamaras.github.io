Area of work

Security Exposure & Detection

My security operations work has covered both externally visible weaknesses and the telemetry needed to investigate activity inside the environment.

External exposure and BitSight

I investigated TLS, certificate and configuration findings reported against public-facing services. That meant validating the underlying issue, identifying the affected service and its owner, and working with technical teams on remediation.

Some findings required tracing public domains back to cloud-hosted services before the right remediation owner and technical fix could be established.

Arctic Wolf and security monitoring

I evaluated the organisation’s existing endpoint protection and monitoring arrangements and helped drive the decision to adopt Arctic Wolf, consolidating capabilities previously provided by Sophos and Proficio.

My work continued into the technical rollout: deploying the Arctic Wolf Aurora agent and Sysmon through Intune, preparing network sensors and investigating Windows security alerts.

Microsoft Defender and endpoint hardening

I configured Microsoft Defender for Endpoint protections and implemented security baselines through Intune for managed Windows devices. This included endpoint hardening settings, policy targeting and reviewing the resulting configurations.

Application security testing

I established an Azure-hosted OWASP ZAP testing environment secured through Bastion for authorised assessments of web applications. I reviewed findings, passed actionable issues to technical owners and assessed the limitations of unauthenticated testing against SSO-protected applications.
